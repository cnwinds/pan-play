# 0004 装过的游戏记下能不能玩，按内容指纹认

状态：已接受（2026-10-18）

## 背景

有些网盘里的游戏装好后玩不了。想把「这个版本能不能玩」记下来，下次看到就知道要不要装。难点在怎么认出「同一份内容」：

- 同一个游戏常有多个来源、多种打包，有的好有的坏，要各记各的。
- 网盘里的游戏目录会被改名、挪走、删掉，以后再转存回来，评价要还在。
- 游戏库一次列几十上百个游戏，不能为了评价多发请求。

## 决定

### 内容指纹

百度列目录时给每个文件返回 `md5`，按文件内容算：改名、挪目录、删了再从同一个分享转存都不变，不同来源、不同打包的不一样。盘游列目录时本来就拿到了，存进 `DriveEntry::content_hash`，没有额外请求。

一组压缩包（主游戏或某个补丁）的指纹 = 各分卷 `md5` 排序后算 FNV-1a（两遍，32 个十六进制字符），开头写 `m`。网盘没给 `md5` 的分卷按大小算，开头写 `s`，表示没那么可靠。都不看文件名和目录名（`content_fingerprint`）。

游戏的版本指纹 = 主游戏那组的指纹。评价按它存。

### 评价记什么

能玩还是有问题（两档）、有问题时的一句说明、评价时主机的固件版本（PS5 上自动读；在电脑上通过 FTP 装的读不到，记为空）、评价时间、当时界面上的游戏名，以及当时装着的各组压缩包（指纹和第一个分卷名）。以后打开时补丁组合和当时不同，横幅上提示一句；旧版装的游戏不知道装了哪几组，不提示。

### 存储和性能

数据目录的 `reviews.json`，一条几百字节。第一次用时读进内存按指纹建索引，查询不走网络；改了才写回（先写临时文件再改名）。评价还会同步到网盘，给别的设备和盘架看，见 [0006](0006-sync-reviews-via-netdisk.md)。

- 详情页：本来就要列游戏目录里的压缩包，顺手算指纹。主游戏的指纹也存进详情缓存（`game-details.json` 的 `fingerprint`）。
- 游戏库格子：只列一级目录看不到压缩包，所以只对打开过详情或装过的游戏，用详情缓存里的指纹查评价（`cached_game_fingerprint`，一次 map 查询），不多发请求。
- 同一个 Title ID 的其他版本评过时，没装的游戏详情页提示一句。

### 界面

- 评过的版本：「安装」按钮上方一条横幅，能玩是绿色、有问题是红色，带说明、固件和日期；封面左下角一个小角标。
- 装好还没评：按钮上方问「装好了，能正常玩吗？」，点「有问题」再选常见原因或写一句。可以「以后再说」，「⋯」里随时能评价、修改或清除。
- 装的时候发现主游戏那组压缩包里是 PKG 安装包（盘游装不了），自动记成有问题，说明写「是 PKG 安装包，盘游装不了（安装时自动标记）」。PKG 在补丁组里时不记：跳过那组主游戏照样能装。已经评过的不覆盖。

## 以后

同一个分享被不同的人转存后 `md5` 一样，所以指纹可以跨用户共享，做成公共评价库（只传指纹、结论和固件，不传网盘路径）。现在只在同一个网盘账号的设备之间同步（[0006](0006-sync-reviews-via-netdisk.md)）。
