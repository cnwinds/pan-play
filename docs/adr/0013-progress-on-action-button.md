# 0013 安装进度画在详情页的主按钮上

状态：已接受（2026-11-14）

## 背景

详情页的安装区越堆越多：主按钮下面有百分比、预计几点装完、「12.3 GB / 79.1 GB · 42 MB/s」、「字典 256 MB · 主要在等下载」、暂停链接，暂停后换成一条「上次装到…」的淡色进度条，排队时又换成一行排队说明和三个链接；装好后还留着「已安装 PPSA08560」「要在主机上安装的包：…已装好」。用户真正要看的只有两件事：装到哪了、装得多快。其余的是开发者排查慢在哪时要的。

## 决定

主按钮本身就是进度条。用户看填充和文字；其余信息用纹理、颜色、长度画在同一个按钮上，开发者照下面的表读，用户不用懂。鼠标悬停（`title`）给开发者全文：阶段、已装 / 总量、最近和平均速度、预计几点装完、字典、慢在哪。

### 用户看的

| 情况 | 文字 | 填充 | 点按钮 |
| --- | --- | --- | --- |
| 正在解压 | `63% · 42.1 MB/s`（速度是最近 10 秒的） | 蓝色实心，宽度 = 进度 | 暂停（右侧 ❚❚） |
| 自己暂停了（没装完） | `继续安装 · 63%` | 半透明蓝，停在暂停时的进度 | 继续（右侧 ▶） |
| 整个队列暂停 | `已暂停 · 63%` | 同上 | 全部继续（右侧 ▶） |
| 排队 | `排队中` | 半透明蓝（之前装过一部分时） | 不能点；「先装这个」「移出安装队列」在「⋯」里 |
| 装好了 | `已安装` | 无（绿色完成样式） | 不能点 |

装好、自己暂停都不再另起一行文字；只有装不下去的原因（出错、断线重试放弃、空间不够）还在按钮下面用琥珀色说。要在主机上安装的包只列没装上的。

### 开发者看的

阶段（`data-phase`）看填充的纹理：

| 纹理 | 阶段 | 对应服务端的 message |
| --- | --- | --- |
| 没有填充，一道浅蓝光带从左扫到右 | prep：还没开始解压 | 核对分享链接、转存到网盘、腾网盘空间、正在读取压缩包… |
| 蓝 / 浅蓝 45° 斜纹，宽度 = 已核对的文件比例 | check：续装前核对已装的文件 | 正在核对（`files_checked / files_to_check`） |
| 蓝色实心 | copy：解压写盘 | 正在安装 |
| 填满，明暗呼吸 | finish：搬到游戏目录、写完成标记 | 正在收尾 |
| 填满，一道白色光带扫过 | console：注册到主机桌面、装激活包 | 正在注册到主机桌面…、正在下载 / 安装要在主机上安装的包… |
| 填充变淡 | pausing：点了暂停，正停在能续装的地方 | 正在暂停… |
| 琥珀色实心 | retry：断线了，倒数后自动续装 | 安装中断，N 秒后自动继续 |

copy 阶段按钮底边有一条 3 像素的细条：

- 颜色是最近 10 秒主要卡在哪（`slow`）：青色 `#3fd0ff` 等下载，紫色 `#b48cff` 解压，橙色 `#ff9f43` 内存放不下字典、在等换页，绿色（`--mint`）写盘；白色是还没判断出来。
- 长度是这层压缩包的字典大小（`dictionary`），按对数从 1 MB（几乎看不见）到 4 GB（铺满），字典每翻一倍长 1/12：64 MB 在一半，256 MB 在 2/3。字典不到 1 MB（ZIP 等）但判断出了卡在哪时，留一小段显示颜色。

## 不做

- 剩余时间不在按钮上显示，放进悬停提示：用户要的是进度和速度两个数。
- 游戏库格子、底部安装栏不改，照旧。

## 影响

- 暂停、继续、全部继续都在主按钮上点；排队相关的「先装这个」「移出安装队列」挪进「⋯」菜单。
- 按钮上的纹理和颜色是给开发者对照的约定，改了要同步这张表。
