# 0006 评价存到网盘，各设备和盘架都读

状态：已接受（2026-10-20）

## 背景

评价（[0004](0004-game-reviews.md)）原来只记在本机。实际用起来有三处要看到它：

- PS5 上的盘游和电脑上的盘游：在哪台上评的，另一台也该知道。
- 盘架（往网盘里转存游戏的工具）：分享里的文件和标记过不能玩的那份一模一样时，就不要再花时间转存；网盘里已经有的，可以一键清掉。

三者共同能读写的只有同一个百度网盘账号，不需要另起服务、也不用配置。

## 决定

### 位置和格式

每台设备写一个文件 `/盘游/评价/<设备 ID>.json`，只写自己的、只读别人的，不会互相覆盖。设备 ID 是第一次同步时随机生成的 16 位十六进制，存在数据目录的 `device-id`；设备名 PS5 上是「PS5」，电脑上是「电脑 计算机名」。

```json
{"version":1,"device":{"id":"…","name":"PS5"},"updated_at":1792475056,
 "reviews":[{"fingerprint":"m…","title_id":"PPSA05106","name":"…","playable":false,"note":"…","firmware":"…","at":1792475056,
             "layers":[{"fingerprint":"m…","name":"…"}],
             "parts":[{"md5":"…","size":1584997444,"name":"PPSA05106-app0.rar"}]}]}
```

`parts` 是主游戏那组各分卷的 `md5`、大小和文件名。盘架拿分享里列出来的文件对：分享里包含某条评价的全部分卷 `md5`，就是评过的那份。这样盘架不用照搬盘游怎么把压缩包分组、怎么算指纹。旧评价没有 `parts`，打开一次那个游戏的详情（实时列网盘时）补上。

### 合并：以最新为准，清除也要传

同一个指纹在几台设备上都评过时，取 `at` 最大的那条显示（自己的和别人的一样大时取自己的）。清除评价不删记录，而是记一条 `removed: true` 的墓碑，时间晚于原来那条，这样别的设备上的旧评价也会被它盖住。改评价时如果别的设备上那条更新（时钟不准），把这次的时间调到比它晚一秒。

别的设备的评价缓存在 `reviews-devices.json`，没网时也能显示；网盘上那台设备的文件没了，它的评价也跟着去掉。

### 什么时候传、什么时候读

- 评价改了（含 PKG 自动标记、补上 `parts`）3 秒后上传整份文件；没登录或失败一分钟后再试。上传成功前 `reviews.json` 里记着 `pending_upload`，重启后接着传。
- 启动后读一次别的设备的文件，之后每 10 分钟一次；打开游戏库时超过 2 分钟没读也读一次。只重读 `fs_id` 变了的文件（覆盖写一次 `fs_id` 就变）。
- 上传用 `d.pcs.baidu.com` 的 `upload`（`ondup=overwrite`，目录不存在会自动建）；下载用 `filemetas` 拿 `dlink`。写小文件是 `DrivePlugin::write_small_file`，目前只有百度实现。

### 盘架那边

- 每 30 分钟读一次 `/盘游/评价`，转存前和打开游戏库时会按需再读。
- 自动转存：分享里的文件和某条「不能玩」评价对得上就跳过，链接标为「盘游说不能玩」，发一条通知。列不出分享内容时照常转存，不因为查不到而拦。
- 手动加入网盘：对得上时弹窗说明，可以「仍然加入」，之后自动转存也不再拦这条链接。
- 游戏库格子上标能玩 / 不能玩（实线是就是这份资源，虚线是只有游戏编号对得上）；网盘页列出网盘里还占着空间、按 `md5` 确认是不能玩的那份的游戏，可以一键退出网盘。
