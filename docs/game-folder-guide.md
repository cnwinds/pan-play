# 网盘游戏目录整理指南

盘游从网盘的**游戏库目录**里读游戏，每个子目录算一款游戏。本文说明一款游戏的目录里，主游戏和补丁的压缩包该怎么放、怎么起名，盘游按什么顺序把它们叠到主机上，以及出了新补丁时怎样只装补丁。

## 一、推荐的目录结构

```
<游戏库目录>/                                  例如 /apps/盘游
└── 艾尔登法环 PPSA04609/                      一款游戏一个目录，名字里带 Title ID
    ├── EldenRing.part1.rar                    主游戏：直接放在游戏目录里
    ├── EldenRing.part2.rar
    ├── EldenRing.part3.rar
    ├── 补丁01 v1.05/                          正式补丁：每个补丁单独一个子目录
    │   └── EldenRing-v1.05.rar
    ├── 补丁02 v1.10/
    │   ├── EldenRing-v1.10.part1.rar
    │   └── EldenRing-v1.10.part2.rar
    └── backport.zip                           固件补丁（可选）：直接放在游戏目录里
```

一句话：**主游戏放在游戏目录里，正式补丁按先后各占一个子目录，子目录名用数字排序。**

## 二、游戏目录

- 每款游戏一个目录，直接放在游戏库目录下面。目录下面再放一层子目录（补丁）可以，更深的层级不会扫描。
- 目录名里要带 Title ID：PS5 是 `PPSA` 加 5 位数字，PS4 是 `CUSA` 加 5 位数字，位置不限，大小写都行，比如 `艾尔登法环 PPSA04609`、`PPSA04609-EldenRing`。
  - 主机上的安装目录就用这个 Title ID：`<存放位置>/PPSA04609/`。
  - 封面、中文名也靠它从商店查。
  - 没有 Title ID 时用整个目录名作为安装目录名，也查不到资料，不推荐。
- 一个目录里只放一款游戏。两款不同的游戏放在同一个目录里，会被当成"游戏 + 补丁"叠在一起。

## 三、压缩包格式

| 支持 | 写法示例 |
|---|---|
| 单个 ZIP | `game.zip` |
| 分卷 ZIP | `game.z01`、`game.z02` … `game.zip`；或 `game.zip.001`、`game.zip.002` … |
| 单个 RAR | `game.rar` |
| 新式分卷 RAR | `game.part1.rar`、`game.part2.rar` … |
| 旧式分卷 RAR | `game.rar`、`game.r00`、`game.r01` … |
| 单个 7z | `game.7z` |
| 分卷 7z | `game.7z.001`、`game.7z.002` … |

- 同一组分卷的文件名主干要一致，盘游靠它把分卷归成一组。一组分卷算一"层"。
- 7z 用 7-Zip 默认设置压的都能装（LZMA2，可执行文件自动加 BCJ 过滤器），固实不固实都行。用了 PPMd、BCJ2 或加了密码的不能装。
- RAR 和 7z 解压时要把整个字典放进内存，字典超过设置里「解压」的上限（默认 PC 4 GB、PS5 512 MB）的包不装。WinRAR 默认字典 32 MB，7-Zip 最高压缩 64 MB，一般都在上限以内。
- 只装着 `.pkg` 安装包的压缩包不能装。盘游只装解压好的游戏文件夹，PKG 要在主机上用安装包工具装。

### 压缩包里面的结构

不用特意整理压缩包内部。盘游会找 `sce_sys` 所在的那一层作为游戏根目录，外面包着的目录（如 `Release/PPSA04609-app0/`）会自动去掉。根目录之外的文件（如资源站的说明 txt）不装，并在结果里提示跳过了几个。

但**一个压缩包里只能有一个游戏根目录**。同一层出现两个带 `sce_sys` 的目录时会报"压缩包里有多个游戏目录"。

## 四、三种"层"

盘游把每组压缩包当成一层，解压后按顺序叠到主机上，后叠的覆盖先叠的同名文件。层分三种：

| 种类 | 怎么认出来 | 放在哪 |
|---|---|---|
| 主游戏 | 游戏根目录下有 `sce_sys/param.json`（PS5）或 `sce_sys/param.sfo`（PS4） | 游戏目录里 |
| 正式补丁（版本更新） | 同上，也带 param 文件 | 每个补丁一个子目录 |
| 固件补丁（backport、修正） | 不带 param 文件，通常只有 `eboot.bin`、`sce_module` 等 | 游戏目录里，或单独的子目录 |

主游戏和正式补丁都带 param 文件，盘游靠**放在哪里、叫什么名字**来区分谁先谁后，所以要按下面的规则放。

## 五、叠放顺序

盘游按下面的规则排出顺序，依次叠上去：

1. **带 param 的层在前，不带的在后。** 所以固件补丁总是最后叠，盖在最新版本的 `eboot.bin` 上。
2. **同一类里，游戏目录里直接放的在前，子目录里的在后。** 所以主游戏放在游戏目录里，补丁放进子目录，主游戏就一定排在所有补丁前面。
3. **子目录之间按子目录名排。**
4. **同一处有多组压缩包时，按第一个分卷的文件名排。**

排序时不分大小写，**名字里的连续数字按数值比**：`补丁2` 排在 `补丁10` 前面，`v1.5` 排在 `v1.10` 前面。为了一眼看清，建议子目录名以两位序号开头：`补丁01 v1.05`、`补丁02 v1.10`、`补丁03 v1.21`。

上面的推荐结构，叠放顺序是：

```
1. EldenRing.part1~3.rar   主游戏
2. 补丁01 v1.05/           正式补丁
3. 补丁02 v1.10/           正式补丁
4. backport.zip            固件补丁（不带 param，排最后）
```

装完后，主机上每个文件都是"最后一个带它的层"里的版本。

### 覆盖和冲突

- 后叠的层覆盖先叠的同名文件，包括主游戏被补丁覆盖、补丁被更新的补丁覆盖、任何层被固件补丁覆盖。
- 几个压缩包里都有的同名文件，内容完全一样时（比如资源站塞的说明文件）只留一份，不算冲突。
- 只有一种情况会报"压缩包里有重复文件，分不出哪个该覆盖哪个"：**同一处（游戏目录里，或同一个子目录里）放了两个固件补丁，又都改了同一个文件。** 这时把它们分到两个按顺序命名的子目录里。
- 同一个路径在一层里是文件、在另一层里是目录，也会报重复文件。

### 不推荐的放法

- **主游戏和正式补丁都直接放在游戏目录里。** 这时按文件名排，`Game.part1.rar` 和 `Game v1.05.rar` 谁在前取决于字符，容易把补丁排到主游戏前面，旧文件反过来盖住新文件。
- **好几个正式补丁放在同一个子目录里。** 同样只能按文件名排，要确认文件名的排序就是版本顺序。

## 六、出了新补丁：只装补丁

游戏已经装好，后来又出了新版本补丁，只要**往这款游戏的目录里加一个新的补丁子目录**，其他压缩包一个都不动：

```
艾尔登法环 PPSA04609/
├── EldenRing.part1~3.rar
├── 补丁01 v1.05/
├── 补丁02 v1.10/
├── 补丁03 v1.21/          ← 新加的
└── backport.zip
```

然后在盘游里打开这款游戏的详情。盘游会拿主机上的完成标记和网盘里现在的压缩包对一下，有变化时按钮变成"安装更新"，封面上标"有更新"。游戏库列表本身不逐个去对，要点开一次详情才看得到；看过之后，列表上这款游戏的封面也会一直标着，直到装完更新。点"安装更新"，盘游会：

1. 读主机上这款游戏的完成标记，标记里按顺序记着上次叠了哪些层。
2. 排出新的叠放顺序，找到第一个新加的层，前面没变的层（主游戏、补丁01、补丁02）原样保留，不下载、不解压。
3. 从第一个新层起往后重新叠：先叠 `补丁03`，再把 `backport.zip` 重新叠一次，因为新补丁可能盖掉了它改过的 `eboot.bin`。
4. 更新完成标记。完成后显示"已更新 PPSA04609，叠上 2 层、写入 N 个文件"。

主游戏几十 GB 不用重下，只下补丁和排在补丁后面的小层。

### 什么时候会整个重装

只装补丁的前提是：**已装的每一层，在新顺序里原样都在，相对顺序也没变**，只是插进了新层。下面几种情况盘游会整个重装，以保证结果正确：

- 删掉了某个已装过的压缩包，比如把旧补丁换成了"整合版"。被它覆盖过的原始文件已经没了，只能从头来。
- 换了已装过的压缩包。盘游按各分卷的文件名和大小认层，改了文件名或换了内容，都算删掉一层、加了一层。
- 改了子目录名，让已装的层之间的顺序变了。只改子目录名、顺序没变时不算变化。
- 新补丁排在了主游戏前面。基本只在"主游戏和补丁都放在游戏目录里"时会出现。
- 这款游戏是用旧版盘游装的。旧版的完成标记里没有逐层记录，第一次更新会整个重装，之后就能只装补丁了。

整个重装时，上次装进去、这次不再有的文件会被清掉。

### 补丁装到一半中断

和普通安装一样，再点一次会从中断处继续，已经解压好的文件不重下。也可以在详情页用"删除已装了一部分的文件"放弃这次更新，删掉的只是暂存区，已装好的游戏本身不受影响。之后重新打开详情，按钮会回到"安装更新"。

## 七、安装前挑选要装的补丁

游戏目录里不止一组压缩包时，点"安装到主机"或"安装更新"不会马上开始，而是先列出全部压缩包让你勾选：

- **主游戏**：直接放在游戏目录里最大的那组（都在子目录里时取最大的）。必装，不能取消。
- **补丁**：子目录里的每组压缩包，按叠放顺序列出。
- **附加**：游戏目录里除主游戏以外的压缩包，多是固件补丁。

每项会标出所在子目录、分卷数和大小，已经装上的标"已装"。底部显示这次要装多少：已经装过的游戏显示"这次新装几项"，从没装过的显示总大小。不想装的取消勾选，点"开始安装"。

选择按游戏记在本机的 `layer-choices.json` 里，之后：

- **继续安装、重试**沿用上次的选择，不再弹出。
- **有没有更新**只看勾选的压缩包。跳过的补丁、以后再放进来但没勾的，都不会让游戏显示"有更新"；新放进来的补丁默认勾上。
- 已装好的游戏可以在详情页点"调整要装的补丁"重新勾选：
  - 勾上之前跳过的补丁，只叠补丁，和第六节一样。
  - 取消一个已经装上的补丁，就和删掉它一样（见上面"什么时候会整个重装"），会从头重装整个游戏，主游戏也要重新下载。面板上会先提示。
  - 只改了没装过的补丁的勾选、不需要装东西时，按钮是"保存选择"，只记下选择。

## 八、一款游戏有几种格式

同一款游戏有 exFAT 镜像版、文件夹版好几份时，每种格式在游戏目录下各占一个 `@格式` 子目录，[盘架](https://github.com/cnwinds/pan-shelf) 按格式转存时就放成这样：

```
极速骑行5 PPSA15190/
├── @exfat/                        exFAT 镜像版
│   ├── PPSA15190-e.part01~12.rar  解压出来是一个 .exfat 镜像文件
│   └── backport files.zip         固件补丁
├── @folder/                       文件夹版
│   └── PPSA15190.part1~8.rar
└── @other/                        资源站没标格式的
```

- 子目录名是 `@` 加小写字母或数字：`@exfat`、`@folder`、`@other`。每个 `@格式` 目录里面照前几节放主游戏和补丁。
- 游戏目录本身不再收 `@格式` 子目录里的压缩包；游戏目录里另外直接放着压缩包时，它也算一种（「没分格式」）。
- 详情页最上面列出几种格式，点哪个就看哪个的压缩包、评价、安装状态。默认选主机上已经装的那种，没装时选 exFAT。
- **主机上同一款游戏只装一种格式**，几种格式都装到同一个 `<存放位置>/<Title ID>/`。已经装了 exFAT 版时，切到文件夹版会显示「主机上装的是 exFAT 镜像版」、不能安装；要换格式先在「⋯」里删除游戏。
- 镜像版装完，主机上的游戏文件夹里是一个 `.exfat` 镜像加上 backport 解压出来的文件。PS5 上的盘游注册时把镜像读写挂载到 `/mnt/panplay/<Title ID>`，把 backport 写进镜像，再注册到桌面；每次开机也由盘游先挂好镜像（见 [ADR 0007](adr/0007-game-format-variants.md)）。PC 版用 FTP 装镜像版时，注册要交给 ShadowMountPlus。
- 只支持 `.exfat`（和 ShadowMountPlus 的 `.ffpkg`）镜像，`.ffpfs` 不支持。资源站标的 fpkg 是 PKG 安装包，装不了。
- 镜像里大段是空的，全零的部分不写盘，装得比镜像大小看起来快。镜像是单个大文件，中途断了要从头解这个文件。

## 九、常见提示

| 提示 | 原因和处理 |
|---|---|
| 这个目录里没有压缩包 | 游戏目录和它下一层子目录里都没有认得出的压缩包 |
| 这个 7z 用了 PPMd / BCJ2 / 加了密码…… | 用 7-Zip 默认设置重新压缩，或换成 ZIP / RAR |
| 字典 N MB，超过上限 M MB，没有安装 | 到设置的「解压」里调高上限后重试；PS5 内存有限，更稳妥的是用更小的字典重新压缩 |
| 内存不够：RAR / 7z 字典要 N MB，主机给不了 | 字典上限调高了或设成不限制。关掉其他程序后重试，或用更小的字典重新压缩；调低上限后这类包会在解压前直接拒绝 |
| 这是 PKG 安装包…… | 压缩包里只有 `.pkg`，要在主机上用安装包工具装 |
| 压缩包里有多个游戏目录 | 一个压缩包里同一层有两个带 `sce_sys` 的目录，拆成两个压缩包，或删掉不要的 |
| 压缩包里有重复文件，分不出哪个该覆盖哪个 | 同一处的两个固件补丁改了同一个文件，分进两个按顺序命名的子目录 |
| 游戏目录名不能作为存放目录 | 目录名里没有 Title ID，剩下的名字又不能当文件夹名（如含 `:`），在目录名里加上 Title ID |
| 这款游戏已经装了X，要换成Y得先删除已装的 | 主机上同一款游戏只装一种格式，先在「⋯」里删除游戏再装另一种 |
| ShadowMountPlus 在运行，镜像版游戏的挂载、注册交给它 | 两边同时读写挂同一个镜像会把镜像写坏。想让盘游来管，先停掉 ShadowMountPlus |
